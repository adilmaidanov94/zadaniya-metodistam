Сюда можно положить фото методистов — они появятся на доске вместо букв.

Имя файла = имя методиста, например:
  Эльмира.jpg
  Улзира.jpg
  Перизат.jpg
  Замдекана.jpg

Подходят форматы jpg, png, webp. Лучше квадратное фото (лицо по центру).
Логотип факультета: положите файл logo.png (или logo.svg) в папку static.
