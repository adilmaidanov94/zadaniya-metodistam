# Задания методистам

Локальный сервис для замдекана: создать задание → перетащить его в колонку методиста
(Эльмира, Улзира, Перизат) → следить за статусом и прогрессом.

**Демо в браузере:** https://adilmaidanov94.github.io/zadaniya-metodistam/
(с примерами заданий; данные хранятся только в вашем браузере, PIN замдекана — `1234`).
Общая доска для всех трёх методистов работает только при запуске локального сервера (см. ниже).

## Запуск
- **Windows:** установить Python с python.org (галочка «Add python.exe to PATH»),
  затем двойной щелчок по `start.bat`. Свой PIN замдекана вписывается в `start.bat`.
- **Mac:** двойной щелчок по `start.command` (или в терминале: `python3 server.py`).

В окне появятся два адреса:
- `http://localhost:8080` — для компьютера замдекана;
- `http://<IP-адрес>:8080` — этот адрес дать методистам (они должны быть в той же сети/Wi‑Fi).

Пока окно сервера открыто — сервис работает. Остановить: Ctrl+C или закрыть окно.

## Роли
- **Замдекана** — вход по PIN (по умолчанию `1234`; сменить: в `start.bat` или `ZAM_PIN=5678 python3 server.py`).
  Создаёт задания, перетаскивает их из «Банка заданий» методистам (и между ними),
  принимает выполненные или возвращает в работу, удаляет.
- **Методист** — выбирает своё имя (или ссылка `http://<IP>:8080/?as=Эльмира`).
  Видит все колонки, но меняет только свои задания: статус (Новое / В работе / На проверке),
  прогресс 0–100 % и комментарий. При 100 % задание само уходит «На проверку».
  «Выполнено» ставит только замдекана.

## Возможности
- Доска «По методистам»: перетаскивание карточек из банка и между колонками, меню «⋮» у каждой карточки.
- Календарь по срокам, список с сортировкой, отчёт по методистам (с печатью).
- Поиск и фильтры по статусу, приоритету и сроку.
- Зелёная точка у аватара — методист сейчас открыла доску.

## Фото и логотип
- Фото методистов: `static/avatars/Эльмира.jpg`, `Улзира.jpg`, `Перизат.jpg` (имя файла = имя).
- Логотип: `static/logo.png` (или `.svg`). Без файлов показываются буквы и стандартная эмблема.

## Данные
Все задания хранятся в `data/tasks.json` (для резервной копии достаточно скопировать этот файл).
У каждого задания есть история изменений: кто и когда менял статус и прогресс.
